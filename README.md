# Smile Hunter

Smile Hunter is a simple Phaser game where players must quickly find and click all smiling faces before time runs out.

## How to Play

* Click on smiling faces to earn points.
* Clicking the wrong face will reduce your score.
* After all smiling faces are cleared, a new set of faces will appear.
* Keep playing until the timer reaches zero.
* Try to achieve the highest score possible.

## Features

* Random face generation
* Score system
* Countdown timer
* Multiple rounds
* Restart functionality

## Built With

* Phaser 3
* Crush Agentic Coding Environment
* BayLeaf API
